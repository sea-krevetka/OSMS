### 2. Краткие теоретические сведения

#### 2.1. Сигнал и его представления
Сигнал — физический процесс, несущий информацию. В радиосвязи сигнал представляется двумя эквивалентными формами:
- временная форма — зависимость амплитуды (напряжения) от времени $u(t)$;
- частотная форма — зависимость амплитуды и фазы от частоты $X(j\omega)$.
Переход между формами осуществляется с помощью преобразований Фурье.

#### 2.2. Ряд Фурье и гармоники
Любой сложный сигнал можно представить суммой гармоник:
$$
s(t) = \sum_{h=1}^{H} A_h \sin(2\pi f_h t + \varphi_h)
$$
Для синтика ноты сделаны как суммы гармоник с кратными частотами $f_h = h \cdot f_0$ и убывающими амплитудами $A_h = 1/h$ (аля пилообразный спектр, характерный для струнных/духовых инструментов).

### 2.3. Теорема Котельникова
Непрерывный сигнал с ограниченным спектром можно точно восстановить по дискретным отсчётам, если частота дискретизации превышает максимальную частоту сигнала минимум в два раза.
$$
f_s \geq 2 f_{\max}
$$
В коде частота дискретизации $f_s = 44100$ Гц, что соответствует стандарту аудио и покрывает весь слышимый диапазон (до 22.05 кГц). 

### 2.4. АЦП и ЦАП

| Этап    | Функция                                                       |
| ------- | ------------------------------------------------------------- |
| **АЦП** | временная дискретизация → квантование по уровню → кодирование |
| **ЦАП** | обратное преобразование отсчётов в непрерывный сигнал         |
В работе звуковая карта выполняет роль ЦАП: массив `float32` отсчётов, формируемый программно, преобразуется в аналоговый звук.

### 2.5. Дискретное преобразование Фурье (ДПФ)
$$
X[k] = \sum_{n=0}^{N-1} x[n]\, e^{-j2\pi kn/N}, \quad k = 0,\dots,N-1
$$
Для визуализации спектра сделан водопадик. По горизонтали частота, по вертикали время. На правильном водопадике цвета и яркость это мощность, тут яркость для красоты. ![[Pasted image 20261121022413.png]]

## 3. Архитектура программы

### 3.1. Таблица нот и частот
Формула пересчёта полутонов относительно A4:
$$
f = 440 \cdot 2^{\,\Delta/12}
$$
где $\Delta$ — число полутонов от A4. Пример:

| Нота | $\Delta$ | $f$, Гц |
|------|----------|---------|
| C4   | −9       | 261.63  |
| E4   | −5       | 329.63  |
| A4   | 0        | 440.00  |
| C5   | +3       | 523.25  |
| F5   | +8       | 698.46  |

### 3.2. Голос (Voice) — огибающая ADSR
Каждый голос реализует амплитудную огибающую:
- **Attack** = 5 мс — линейный рост громкости от 0 до 1;
- **Release** = 150 мс — линейное затухание после отпускания клавиши;
- при `gain ≤ 0` голос помечается `done` и удаляется из списка.
Синтез отсчёта: 

```python
s = Σ h_amp · sin(phase · (h_idx + 1))
out[i] = amp · gain · s
phase += 2π · freq / fs
```


## 4. Результаты

### 4.1. Временная форма сигнала
При нажатии клавиши `a` (нота C4) формируется сумма трёх гармоник:
$$
s(t) = 0.2 \cdot g(t) \left[\sin(2\pi \cdot 261.63\, t) + 0.5\sin(2\pi \cdot 523.25\, t) + 0.25\sin(2\pi \cdot 784.88\, t)\right]
$$
где $g(t)$ — огибающая. Временная форма имеет характерный «ступенчатый» вид из-за наложения гармоник.
### 4.2. Водопадная диаграмма (waterfall)
Отображает эволюцию спектра во времени:
- **ось X** — частота (200…1200 Гц);
- **ось Y** — время (80 временных слотов);
При нажатии ноты на диаграмме появляется яркая горизонтальная полоса на её частоте и кратных гармониках, которая с течением времени сдвигается вверх.
### 4.3. Текущий спектр
Нижний график показывает мгновенный амплитудный спектр активных нот. Каждая гармоника $h$ ноты с частотой $f_0$ отображается гауссовым пиком:
$$
S(f) = \sum_{h} \frac{1}{h} \exp\!\left(-\frac{(f - h f_0)^2}{2\sigma_h^2}\right), \quad \sigma_h = 2h
$$
Нормировка $S(f) \to S(f)/\max S$ обеспечивает единичную шкалу амплитуд.

### 4.4. Спектр гармоник
Для ноты A4 (440 Гц) с 11 гармониками спектр содержит пики на частотах:

| Гармоника | Частота, Гц | Амплитуда (отн.) |
|-----------|-------------|------------------|
| 1 | 440.0 | 1.000 |
| 2 | 880.0 | 0.500 |
| 3 | 1320.0 | 0.333 |
| 4 | 1760.0 | 0.250 |
| … | … | … |
| 11 | 4840.0 | 0.091 |

Такое распределение амплитуд $1/h$ соответствует пилообразному сигналу и придаёт звуку тембр близкий к настоящим инструментам (по идее, но если честно надо еще сильнее поменять).

def note_freq(semitone_from_A4: int) -> float:
    return 440.0 * 2 ** (semitone_from_A4 / 12)

FREQS = {k: note_freq(v) for k, v in NOTES.items()}

### Синтез отсчётов голоса

```python
def render(self, n):
    out = np.zeros(n, dtype=np.float32)
    for i in range(n):
        if self.released:
            self.gain -= self.release_step
        else:
            self.gain = min(1.0, self.gain + self.attack_step)
        if self.gain <= 0:
            self.done = True
            break
        s = sum(h_amp * np.sin(self.phase * (h_idx + 1))
                for h_idx, h_amp in enumerate(self.harmonics))
        out[i] = self.amp * self.gain * s
        self.phase += 2 * np.pi * self.freq / self.fs
        if self.phase > 2 * np.pi:
            self.phase -= 2 * np.pi
    return out
```

### Построение спектра для визуализации

```python
def _build_spectrum(self, freqs):
    spec = np.zeros_like(self.freq_bins, dtype=float)
    for f in freqs:
        for h, amp in enumerate(HARMONICS, start=1):
            fh = f * h
            if self.freq_bins[0] <= fh <= self.freq_bins[-1]:
                sigma = 2.0 * h
                spec += amp * np.exp(-0.5 * ((self.freq_bins - fh) / sigma) ** 2)
    if spec.max() > 0:
        spec /= spec.max()
    return spec
```
